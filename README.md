# Projeto Final — Análise de Indicadores Macroeconômicos do Brasil

## 1. Sobre o projeto

Este projeto está sendo desenvolvido como atividade final do curso de Visualização de Dados e Business Intelligence.

O objetivo é analisar alguns indicadores econômicos do Brasil, utilizando dados públicos do Banco Central, para entender melhor o comportamento dos juros, da inflação, do câmbio e da atividade econômica.

## 2. Dados utilizados

A análise será realizada com informações do período de 2019 a 2023.

Os indicadores escolhidos são:

- Taxa Selic
- IPCA mensal
- IPCA acumulado em 12 meses
- Dólar PTAX
- IBC-Br

Fonte: Banco Central do Brasil (BACEN).

## 3. Ferramentas utilizadas

- Python e Pandas para coleta e tratamento dos dados
- SQL para consultas e organização das informações
- Plotly Express para criação dos gráficos
- Streamlit para desenvolvimento do dashboard
- Git e GitHub para versionamento
- Trello para organização das atividades

## 4. Desenvolvimento

O projeto será desenvolvido em etapas, começando pela coleta e preparação dos dados, seguida das análises e da construção do dashboard.

Os tratamentos realizados, os indicadores calculados, os resultados e as limitações serão documentados conforme o desenvolvimento do projeto.
